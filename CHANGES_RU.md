# Изменения к AgroShield AI v4

## Сохранено
- React/Vite, Leaflet, создание независимых полей.
- Спутниковый слой Esri и поиск местности через Nominatim.
- Рисование прямоугольника и свободной линии, сохранение GeoJSON и расчёт площади.
- Четыре вкладки: Обзор / Данные поля / AI-рекомендации / История анализов.
- Три стратегии, один предварительный выбор и финальное решение фермера.

## Изменено
- `src/App.jsx`: API NASA и SoilGrids подключены к кнопкам в соответствующих вкладках; реальные показатели показываются из ответов сервера; появилась форма гербицидов с явным статусом и сохранение черновика; PDF и XLSX добавлены в проверяемую загрузку.
- `src/dataService.js`: клиентский HTTP API с тайм-аутом, ошибками и передачей границ.
- `server/app.py`: FastAPI эндпоинты health, nasa, soil, files/preview, files/commit.
- `server/nasa.py`: многолетние данные NASA POWER с климатической нормой 1991–2020 и кэшем.
- `server/soil.py`: SoilGrids WCS GetCoverage, GeoTIFF, медиана по площади поля, конверсия единиц, локальный кэш. Исправлен коэффициент для процентов песка, пыли и глины: деление raw на 10 для перевода г/кг в проценты.
- `server/imports.py`: извлечение CSV/XLSX и текста PDF, сохранение листа и строки, ручное подтверждение.
- `src/rotationEngine.js`: качество выбора отображается отдельно от факта наличия NASA/SoilGrids; неизвестные гербициды — запрос на уточнение, не запрет.
- `src/fieldUtils.js`: миграция v3→v4 сохраняет прежнюю историю и введённые данные фермера.
- `server/tests/test_pipeline.py`: четыре теста конверсии, NASA-периодов, импорта и API.

## Что ещё не завершено
- Проверка **живой** доступности NASA POWER и SoilGrids WCS (нужна сеть в среде запуска).
- Автоматический разбор лабораторных значений из PDF (пока хранится оригинал).
- Сортовые требования, научно валидированная оценка гербицидного последействия и экономика культур.
- Надёжный серверный рейтинг и реальная LLM-интеграция вместо качественных сценариев.
- Серверная база данных, логин и масштабируемый хостинг.
