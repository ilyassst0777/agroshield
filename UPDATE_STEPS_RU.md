# Обновление AgroShield: пошагово

## Что подготовлено

Вкладка AI-рекомендаций теперь вычисляет варианты в браузере по данным выбранного поля. Внешняя нейросеть не подключена и API-ключ не требуется. Это прозрачный пилотный расчёт, не подтверждённый прогноз урожая.

## Как обновить сайт

1. Распакуйте архив. Откройте папку agroshield-main.
2. Откройте существующий репозиторий проекта на GitHub. Замените файлы проекта содержимым этой папки, сохраняя прежнюю структуру: src остаётся src, server остаётся server. Не создавайте дополнительную вложенную папку agroshield-main в корне репозитория.
3. Сохраните изменения в рабочую ветку. Если настроено автоматическое развёртывание, Vercel соберёт интерфейс после обновления подключённой ветки.
4. Обновите также Python API на Render из того же обновлённого кода. Если автоматическое развёртывание выключено, запустите Deploy latest commit в существующем сервисе. Путь server/nasa.py содержит исправление влажности. Настройка vercel.json по-прежнему направляет /api на прежний сервис agroshield-api.onrender.com.
5. Проверьте успешный статус обоих развёртываний и обновите страницу AgroShield.

Сам опубликованный сайт из этой сессии не изменён: подготовлен исходный проект для замены в вашем репозитории.

## Как пользоваться

1. Выберите поле. В «Данные поля → Посевы» добавьте реальную культуру за год перед началом плана. Для плана с 2027 года нужна запись за 2026 год. Она не добавляется автоматически.
2. Внесите известные сведения о почве и поливе. Загрузите или обновите NASA в «Климат и вода».
3. Откройте AI-рекомендации. Подтвердите предложенные наблюдения из заметок, если они соответствуют реальному состоянию поля.
4. Выберите цели, бюджет, состав расходов и период бюджета: каждый сезон или все три года.
5. В «Условия подбора» укажите первый год, доступные культуры, известные затраты на гектар. При необходимости раскройте ограничения культур: запреты, интервалы возврата, pH, полив и сроки. Значения местных правил и цен нужно ввести самостоятельно; вымышленных рыночных цен нет.
6. Нажмите «Сохранить условия», затем «Рассчитать севооборот».
7. Сравните до трёх первых вариантов. Откройте полноту расчёта, расходы и причины исключения. При равных баллах уникальный победитель не заявляется.
8. Собственный севооборот проверяется тем же движком. Выберите три культуры и нажмите «Проверить свой вариант».
9. Сохраните черновик или утвердите выбранную карточку после необходимых проверок. В историю сохраняются выбранные культуры, оценки, версия правил и копия исходных сведений. После изменения данных требуется пересчёт.

## Как считается

Перебираются все сочетания выбранных культур на три года: четыре культуры дают 64 варианта. Заданные ограничения проверяются до ранжирования, включая возврат внутри нового плана. Расходы равны цене на гектар × площади; неизвестная цена не считается нулём. pH SoilGrids не создаёт жёсткий запрет как лабораторное измерение.

Шесть критериев: история, климат, вода, почва, расходы, предпочтения. Веса меняются с целями. Недостающие критерии исключаются из среднего, учтённый вес показан отдельно. Числовые штрафы и сравнительная чувствительность — явно описанные пилотные допущения, не коэффициенты FAO или научная валидация местного сорта.

Исторические осадки влияют через долю сухих сезонов относительно опорного уровня. Средняя температура используется при заданном пользователем ориентире средней температуры мая–августа. Месячные средние не выдают дневные экстремумы. Урожайность, прошлые даты, радиация, ветер, свободные цели и PDF сохраняются как контекст; дополнительные числовые эффекты без модели не выдумываются. Подтверждённые строки табличного импорта участвуют в истории.

Хранение остаётся в localStorage браузера; это не серверная база и данные не синхронизируются между устройствами.

- 4 теста Python API и обработки данных.

- Живой NASA GWETROOT: HY возвращает 422; AG возвращает 200. Запрос исправлен на AG, кэш NASA обновлён до v5.
